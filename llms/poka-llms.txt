# Poka

> Poka is a manufacturing-focused connected worker platform (part of IFS) that helps industrial and frontline teams standardize work execution across learning, daily management, and operations. It combines digital work instructions, on-the-job training, skills management, and factory-floor knowledge sharing with embedded Industrial AI. Poka exposes a RESTful Poka API for integrations with third-party systems (MES, CMMS, LMS, QMS, ERP, BI), SCIM for automated user provisioning, the Poka Automate iPaaS, and a Poka Data Lake for BI/reporting. Developer/API documentation is delivered per-tenant and via a password-gated reference portal; no public OpenAPI is published.

## APIs

- [Poka API](https://www.poka.io/en/integrations): RESTful API for building integrations with third-party manufacturing and enterprise systems, plus SCIM for automated user provisioning.
